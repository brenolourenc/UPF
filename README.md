## Important source-fidelity notice

This package contains:
- A newly consolidated general overview.
- Recovered project decisions and architectural summaries.
- Catalogues of known specifications, contracts and reviews.
- Registers identifying missing primary-source text and unresolved decisions.

It does **not** contain the complete original text of every specification or contract previously drafted in ChatGPT. In particular, the original wording of the 80 Open Decisions (ODs) has not been recovered into this package. Summaries are explicitly labelled as summaries and must not be treated as authoritative substitutes.

## Repository principles

- Preserve source documents; do not silently rewrite or replace them with summaries.
- Keep proposed decisions separate from owner-approved decisions.
- Do not mark an OD resolved without examining its original text and recording a justified disposition.
- Do not claim implementation, testing or validation without evidence.
- Use Git to track all project changes.
- Ask the Project Owner before making reserved or material decisions.
